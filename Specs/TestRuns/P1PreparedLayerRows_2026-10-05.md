## Ownership and authority

Admission reads sealed cached source/name bounds before retaining the immutable document. Workers prepare top-first hierarchy, inherited visibility/collapse, localized hidden text and a sorted Guid index. Owner lookup takes at most 14 binary-search iterations at 10,000 layers, including adversarial hash collisions, with one equality and at most one ordering comparison per iteration. The result owns the original source and all derived rows/names/indexes; its last destruction runs on a worker.

The host key binds session read authority, document serial, generation, restore lineage, held layer-root descriptor and separate monotonic collapse revision. Collapse/expand A-B-A cannot revive an older result. Copy/move sessions have fresh authority even with identical roots/ids/counters. Locale is the process's startup STRINGTABLE selection; settings language applies at the next start. The hidden pattern is captured once before enabling.

The admitted owner stage captures the document in constant size and copies at most 10,000 collapse Guids (160 KB). This declared finite metadata traversal copies no row/name/selection/history/pixel graph, but still needs measured owner qualification. Cancellation retains the original record/source/reservation until acknowledgement. One active request and one newest key avoid polling or accumulated refreshes.

Successful completion transfers the original reservation into a fixed retained-memory slot with no second admission/query/allocation. Charged cache bytes do not keep useful work awake. Chrome borrows the prepared result; replacement changes the borrow before retiring the old owner. Complete worker retirement is queued before releasing retained accounting, with deferred-release bytes protecting the destruction interval. Close detaches borrowing while sink/pool lifetime remains valid. A token owns accounting only, never source lifetime.

Current refresh keeps same-document labels visible with the stale tree disabled; document replacement clears old labels immediately. Disabled rows refuse mask-target hits too. Current failure reports the localized layer-list error and publishes no candidate. The newer replacement extension refuses insufficient admission once while preserving the old cache charge; only explicit Retry or a changed key requests another ticket.
